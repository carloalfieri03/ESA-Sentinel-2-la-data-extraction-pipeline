The following scripts extract satellite metadata from the Copernicus Stac API (https://browser.stac.dataspace.copernicus.eu/collections/sentinel-2-l2a?.language=en). 

To extracts the csvs run before import.py to extract the json file from the API with the coordinates of interest and then run sqldata.py to extract the metadata from the json file and output the csvs used for tables population.
